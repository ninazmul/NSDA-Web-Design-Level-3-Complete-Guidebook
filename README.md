## 🛠️ Tech Stack

This guidebook is built with pure web technologies — **no frameworks, no build tools, no dependencies**.

```
HTML5        → Semantic structure & accessibility
CSS3         → Custom properties, Grid, Flexbox, animations
JavaScript   → Theme toggle, scroll spy, search, interactivity
```

| Technology | Purpose |
|-----------|---------|
| **HTML5** | Semantic page structure, SEO-optimized markup |
| **CSS3** | Design system with CSS variables, responsive layout, glassmorphism |
| **Vanilla JS** | Theme persistence, scroll spy, search, accordion, copy-to-clipboard |
| **Google Fonts** | Inter & JetBrains Mono for premium typography |

## 🚀 Getting Started

### Quick Start

No installation needed! Simply clone and open:

```bash
# Clone the repository
git clone https://github.com/ninazmul/nsda-web-design-l3-guidebook.git

# Navigate into the project
cd nsda-web-design-l3-guidebook

# Open in your browser
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

### Using Live Server (Recommended)

For the best development experience with auto-reload:

```bash
# If you have VS Code with Live Server extension:
# Right-click index.html → "Open with Live Server"

# Or use npx:
npx serve .
```

## 📜 About NSDA

The **National Skills Development Authority (NSDA)** is a Government of Bangladesh organization responsible for coordinating and promoting skills development. This guidebook follows the **Competency Standard CS-ICT-WD-L3-EN-V2**, approved by the 39th Authority Meeting on **23 January 2025**.

### BNQF Level 3 — Skilled Worker

| Dimension | Requirement |
|-----------|-------------|
| **Knowledge** | Moderately broad knowledge in a specific work area |
| **Skills** | Basic cognitive and practical skills for routine problem-solving |
| **Responsibility** | Work under supervision with considerable autonomy |
