Unit 7: Work with CSS and Use CSS Framework for Web Design

Unit Code: OU-ICT-WD-04-L3-V2
This unit covers interpreting and applying CSS, using responsive design, CSS Grid, transitions, animations, and CSS frameworks like Bootstrap and Tailwind CSS.

📋 Overview

CSS (Cascading Style Sheets) controls the visual presentation of web pages. From colors and fonts to complex layouts and animations, CSS transforms plain HTML into beautiful, responsive websites.

🎨 Element 1: Interpret and Structure CSS

CSS Syntax

CSS
/* CSS Rule Structure */
selector {
  property: value;
  another-property: another-value;
}

/* Example */
h1 {
  color: #38bdf8;
  font-size: 2.5rem;
  font-weight: 700;
  margin-bottom: 1rem;
}

📐 Element 2: Apply CSS for Layout and Styling

📦 The CSS Box Model

📦 Every HTML element is a box with 4 layers:

Content → The actual text, image, or element content

Padding → Space between content and border (inside the box)

Border → The visible edge of the box

Margin → Space outside the border (between this box and others)

CSS
.card {
  width: 300px;
  padding: 20px;          /* Inside space */
  border: 1px solid #ccc;  /* Visible edge */
  margin: 16px;           /* Outside space */
  box-sizing: border-box; /* Include padding in width */
}

✨ Transitions, Gradients & Animations

CSS
/* Transition — smooth state changes */
.button {
  background: #38bdf8;
  transition: all 0.3s ease;
}
.button:hover {
  background: #0ea5e9;
  transform: translateY(-2px);
  box-shadow: 0 4px 12px rgba(56, 189, 248, 0.3);
}

/* Gradient — smooth color blends */
.hero {
  background: linear-gradient(135deg, #38bdf8, #a78bfa);
}

/* Animation — keyframe-based */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
.card {
  animation: fadeIn 0.6s ease forwards;
}

/* 2D Transform */
.rotate { transform: rotate(45deg); }
.scale { transform: scale(1.1); }

/* 3D Transform */
.flip { transform: perspective(600px) rotateY(180deg); }

🔲 Element 4: CSS Grid System

CSS
/* CSS Grid — Create a 3-column layout */
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 equal columns */
  grid-gap: 1.5rem;                       /* Space between items */
}

/* Responsive Grid */
.responsive-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 1rem;
}

/* Grid Areas — complex layouts */
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 250px 1fr;
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

/* Flexbox — for one-dimensional layouts */
.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
  flex-wrap: wrap;
}

🎯 NSDA Exam Preparation: Question Bank & MCQs

High-yield exam questions covering CSS3 layouts, Grid/Flexbox, responsive design, and CSS frameworks for NSDA Level 3 certification.

Part 1: Multiple Choice Questions (MCQs)

Basic
1. Why is * { box-sizing: border-box; } universally applied as the standard CSS reset in modern web design?
A It converts all elements into inline spans
B It includes padding and borders inside an element's total declared width and height, preventing layout breakage
C It automatically centers all containers on screen
D It removes all default margins from headings
View Correct Answer & Explanation
Correct Answer: B — Under default content-box, adding padding or border expands the element beyond its set width. border-box absorbs padding/border within the width.
Intermediate
2. Which CSS Grid declaration creates an auto-responsive multi-column card grid that wraps columns automatically without requiring explicit media query breakpoints?
A grid-template-columns: repeat(3, 1fr);
B grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
C grid-template-columns: 280px auto;
D display: flex; flex-direction: row;
View Correct Answer & Explanation
Correct Answer: B — repeat(auto-fit, minmax(280px, 1fr)) dynamically fits as many 280px+ columns as possible on screen, expanding each proportionally with 1fr.
Advanced
3. Between the two CSS rules below, which style will take precedence on a link with ID #nav-link and class .active?
/* Rule 1: */ header nav a.active { color: red; }
/* Rule 2: */ #nav-link { color: blue; }
A Rule 1 (Red) because it contains more selectors
B Rule 2 (Blue) because an ID selector (0,1,0,0) outweighs classes and elements (0,0,1,3)
C Whichever rule appears later in the stylesheet
D Both colors combine into purple
View Correct Answer & Explanation
Correct Answer: B — Specificity math: Rule 1 has 1 class + 3 elements = 0,0,1,3 (score 13). Rule 2 has 1 ID = 0,1,0,0 (score 100). ID always defeats any quantity of class or element selectors.

Part 2: Written & Oral Questions with Detailed Answers

Basic
Q1: Compare the difference between Flexbox and CSS Grid. When should a web designer choose one over the other?

Flexbox (Flexible Box Layout): A one-dimensional layout system designed for distributing space along either a single row OR a single column. Best for: navigation bars, aligning buttons inside headers, pill badges, and centering single cards.

CSS Grid: A two-dimensional layout system designed for controlling both columns AND rows simultaneously. Best for: complete page scaffoldings, photo galleries, dashboard widget layouts, and responsive card grids.

Intermediate
Q2: What is "Mobile-First" Responsive Web Design, and how does it determine the choice between min-width and max-width media queries?

Mobile-First Design: Writing default base CSS styles for mobile/handheld screens first (simple single-column layouts, touch targets), and progressively layering enhanced styles as the viewport widens.

Media Query Implementation: Always use @media (min-width: 768px) rather than max-width. This ensures lower-powered mobile devices parse the leanest CSS rules without having to override heavy desktop styles.

Advanced
Q3: How do CSS Custom Properties (Variables) improve front-end maintainability and enable real-time dynamic dark/light theme switching?

CSS variables (declared via --name: value; and referenced with var(--name)) are scoped to the DOM tree and dynamically inherit down the hierarchy.

Theme Switching Pattern:

  • Define semantic color tokens under :root for the default dark theme (e.g. --bg-primary: #0a0e1a; --text-primary: #f1f5f9;).
  • Override those exact variable definitions under a [data-theme="light"] attribute selector (e.g. --bg-primary: #ffffff; --text-primary: #0f172a;).
  • Toggling document.documentElement.setAttribute('data-theme', 'light') with JavaScript instantly updates the entire website without rewriting component classes or triggering costly style recalculations.
