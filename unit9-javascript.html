Unit 9: Work with Core JavaScript

Unit Code: OU-ICT-WD-06-L3-V2
This unit covers JavaScript programming fundamentals for web interactivity, including variables, data types, operators, control structures, functions, DOM manipulation, and event handling.

📋 Overview

JavaScript is the programming language of the web. It adds interactivity, dynamic content, and behavior to your HTML pages. Every modern website uses JavaScript — from simple form validation to complex single-page applications.

💡 Where JavaScript Runs

In the Browser: Every modern browser has a built-in JavaScript engine (V8 in Chrome, SpiderMonkey in Firefox). Use the browser console (F12 → Console) to test code instantly.

On the Server: Node.js allows JavaScript to run on servers, enabling full-stack development with one language.

  console.log("Hello from JavaScript!");
</script>

<!-- Method 2: External file (recommended) -->
<script src="js/main.js"></script>

<!-- Method 3: Inline (avoid in production) -->
<button onclick="alert('Clicked!')">Click Me</button>

🔄 Loops

JavaScript
// for loop — when you know the count
for (let i = 0; i < 5; i++) {
  console.log(`Iteration ${i}`);
}

// for...of — iterate over array values
const colors = ["red", "green", "blue"];
for (const color of colors) {
  console.log(color);
}

// for...in — iterate over object keys
const user = { name: "Nazmul", age: 25, role: "Developer" };
for (const key in user) {
  console.log(`${key}: ${user[key]}`);
}

// while loop — when condition is checked first
let count = 0;
while (count < 3) {
  console.log(`Count: ${count}`);
  count++;
}

// do...while — runs at least once
let num = 10;
do {
  console.log(`Number: ${num}`);
  num++;
} while (num < 5);
// Prints "Number: 10" (runs once even though 10 < 5 is false)

// break and continue
for (let i = 0; i < 10; i++) {
  if (i === 3) continue; // Skip 3
  if (i === 7) break;    // Stop at 7
  console.log(i);         // 0, 1, 2, 4, 5, 6
}

  return numbers.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4, 5)); // 15

📌 What is the DOM?

The Document Object Model (DOM) is a tree-like representation of your HTML document. JavaScript uses the DOM to read, modify, add, and remove HTML elements dynamically — making web pages interactive without reloading.

🎯 DOM Selection Methods

JavaScript

// Select by class name (returns HTMLCollection)

// Select by tag name

💡 Practical Examples

Example 1: Dark Mode Toggle

JavaScript
const toggleBtn = document.querySelector("#theme-toggle");
const body = document.body;

toggleBtn.addEventListener("click", () => {
  body.classList.toggle("dark-mode");

  // Save preference to localStorage
  const isDark = body.classList.contains("dark-mode");
  localStorage.setItem("theme", isDark ? "dark" : "light");

  // Update button text
  toggleBtn.textContent = isDark ? "☀️" : "🌙";
});

// Load saved theme on page load
if (localStorage.getItem("theme") === "dark") {
  body.classList.add("dark-mode");
}

Example 2: Form Validation

JavaScript
const form = document.querySelector("#contact-form");
const emailInput = document.querySelector("#email");
const errorMsg = document.querySelector("#error-message");

form.addEventListener("submit", (e) => {
  e.preventDefault(); // Stop form from submitting

  const email = emailInput.value.trim();

  if (!email) {
    errorMsg.textContent = "Email is required!";
    emailInput.classList.add("error");
    return;
  }

  if (!email.includes("@")) {
    errorMsg.textContent = "Please enter a valid email!";
    emailInput.classList.add("error");
    return;
  }

  // Success
  errorMsg.textContent = "";
  emailInput.classList.remove("error");
  console.log("Form submitted successfully!");
});

Example 3: Dynamic Content (To-Do List)

JavaScript
const input = document.querySelector("#todo-input");
const addBtn = document.querySelector("#add-btn");
const list = document.querySelector("#todo-list");

addBtn.addEventListener("click", () => {
  const text = input.value.trim();
  if (!text) return;

  // Create new list item
  const li = document.createElement("li");
  li.textContent = text;

  // Add delete button
  const deleteBtn = document.createElement("button");
  deleteBtn.textContent = "❌";
  deleteBtn.addEventListener("click", () => li.remove());

  li.appendChild(deleteBtn);
  list.appendChild(li);
  input.value = ""; // Clear input

Part 2: Written & Oral Questions with Detailed Answers

Basic
Q1: Explain the difference between strict equality (===) and loose equality (==) in JavaScript with examples.

Loose Equality (==): Compares two values for equality after performing implicit type coercion if the data types differ.

Example: 5 == "5" evaluates to true because the string "5" is coerced to number 5.

Strict Equality (===): Compares both the value AND the data type without type conversion. If types differ, it immediately returns false.

Example: 5 === "5" evaluates to false (Number vs String). Strict equality is the required standard in professional development to avoid insidious bugs.

Q3: What are the eight fundamental data types in modern JavaScript?

JavaScript contains 7 Primitive data types and 1 Reference data type:

  • 1. String: Textual characters (e.g. "hello").
  • 2. Number: Integers and floating-point values (e.g. 42, 3.14).
  • 3. BigInt: Arbitrary-precision integers exceeding safe integer limit (e.g. 9007199254740991n).
  • 4. Boolean: Logical entity: true or false.
  • 5. Undefined: Variable declared but not assigned a value.
  • 6. Null: Intentional intentional absence of any object value.
  • 7. Symbol: Unique, immutable identifier token.
  • 8. Object (Reference Type): Collections of key-value pairs (includes plain Objects, Arrays, and Functions).
Basic
Q4: What is the difference between 'null' and 'undefined' in JavaScript?

undefined: The default value automatically assigned by JavaScript when a variable is declared but has not yet been initialized with a value, or when a function does not return an explicit value.

null: An intentional assignment representing the deliberate absence of an object or value. A developer writes let currentUser = null; to explicitly indicate 'nobody is logged in'.

Comparison: null == undefined evaluates to true, but null === undefined evaluates to false.

Intermediate
Q5: Describe the differences between the array methods 'map()', 'filter()', and 'forEach()'.
  • forEach(callback): Executes a provided function once for each array element. It returns undefined and is strictly used for side effects (e.g. logging or appending DOM nodes).
  • map(callback): Transforms each item and returns a new array of the exact same length containing the transformed values. Does not mutate the original array.
  • filter(callback): Tests each item with a boolean condition and returns a new array containing only elements that evaluate to true.
Intermediate
Q6: Explain Event Bubbling, Event Capturing, and how to implement the Event Delegation pattern.

Event Phases:

  1. Capturing Phase: Event travels down from window → document → parent nodes → target node.
  2. Target Phase: Event triggers on the actual clicked node.
  3. Bubbling Phase (Default): Event bubbles up from target node → parent → document.

Event Delegation Pattern: Instead of attaching 100 event listeners to 100 individual list items (<li>), attach ONE listener to their common parent (<ul>). In the handler, check e.target.closest('li') to identify the clicked child. This conserves browser memory and automatically supports dynamically added items without reattaching listeners.

Q7: How do you fetch JSON data from a RESTful API using 'async/await' and handle HTTP errors properly?

Standard production pattern for async fetch with error checking:

async function fetchUserData(userId) {
  try {
    const response = await fetch(`https://api.example.com/users/${userId}`);
    
    // Mandatory: check response.ok (HTTP 200-299)
    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status} ${response.statusText}`);
    }
    
    const data = await response.json();
    console.log("User data loaded:", data);
    return data;
  } catch (error) {
    console.error("Network or API failure:", error.message);
    // Render user-friendly error UI
  }
}

Q9: What is a JavaScript Closure? Provide a practical code example where closures are utilized in front-end development.

Definition: A closure is a function bundled together with references to its surrounding lexical state. In JavaScript, an inner function maintains access to variables declared in its outer enclosing function even after the outer function has finished executing.

Practical Application (Counter / Private State):

function createCartManager() {
  let itemCount = 0; // Private variable protected from global scope
  return {
    addItem: () => { itemCount++; return itemCount; },
    getCount: () => itemCount
  };
}

const myCart = createCartManager();
console.log(myCart.addItem()); // 1
console.log(myCart.addItem()); // 2
console.log(myCart.itemCount); // undefined (safely encapsulated)
Advanced
Q10: Implement a custom Debounce utility function and explain its role in preventing performance degradation during search input.

Debounce Implementation:

function debounce(callback, delayMs = 300) {
  let timerId;
  return function (...args) {
    clearTimeout(timerId);
    timerId = setTimeout(() => {
      callback.apply(this, args);
    }, delayMs);
  };
}

// Usage on a search input:
const searchInput = document.querySelector('#search');
searchInput.addEventListener('input', debounce((e) => {
  console.log('Sending search query to API for:', e.target.value);
}, 400));

Why Essential: Without debouncing, typing 'javascript' triggers 10 rapid API requests on every single keystroke. Debouncing delays execution until the user pauses typing for 400ms, collapsing 10 expensive network requests into a single request.

Advanced
Q11: Explain the JavaScript Event Loop, Call Stack, Web APIs, and Microtask vs Macrotask Queues.

JavaScript is single-threaded, executing one operation at a time on its Call Stack.

  • Call Stack: Executes synchronous code frames in LIFO (Last In, First Out) order.
  • Web APIs: Browser background threads that handle asynchronous timers (setTimeout), network requests (fetch), and DOM events.
  • Microtask Queue (High Priority): Houses Promise callbacks (.then, catch, await resumption) and MutationObserver. The Event Loop drains the ENTIRE microtask queue before rendering or touching macrotasks.
  • Macrotask Queue (Task Queue): Houses setTimeout, setInterval, and UI events. Processed one task at a time after the microtask queue is empty.
Advanced
Q12: How do you identify and prevent memory leaks in single-page JavaScript applications?

Common Causes of Memory Leaks:

  1. Dangling Event Listeners: Attaching listeners to DOM elements without calling removeEventListener when those elements are removed from the page.
  2. Uncleared Timers: Running setInterval loops that reference variables long after the containing component has unmounted.
  3. Accidental Global Variables: Assigning to undeclared variables (e.g. leakVar = 'data' instead of const leakVar), pinning data to the global window object permanently.
  4. Detached DOM Tree References: Storing references to removed DOM nodes in an array or cache object, preventing garbage collection.

Prevention & Diagnostics: Always cleanup timers (clearInterval) and listeners upon unmount. Use Chrome DevTools Memory panel to take Heap Snapshots and inspect detached elements.
