Unit 5: Setup Web Design Environment

Unit Code: OU-ICT-WD-02-L3-V2
This unit covers installing code editors and tools, configuring browsers and extensions, organizing files and folders, using version control systems, and setting up both local and live development environments.

📋 Overview

A well-configured development environment is essential for efficient web design. This unit teaches you to set up everything from code editors to live hosting, ensuring you can build, test, and deploy web projects professionally.

🌐 Element 4: Configure Live Development Environment

Steps to Deploy a Website Live

  1. Choose hosting provider — Research and select (shared hosting, VPS, or cloud)
  2. Register domain name — Purchase a domain (e.g., example.com)
  3. Configure DNS — Point domain to hosting server's IP address
  4. Configure web server — Apache or Nginx settings
  5. Upload files — Using FTP/SFTP (FileZilla) or Git deployment
  6. Verify structure — Ensure file/folder paths match hosting requirements
  7. Configure database — If applicable, set up MySQL/PostgreSQL
  8. Test thoroughly — Check across devices and browsers
  9. Security settings:
    • SSL Certificate: Enable HTTPS (Let's Encrypt is free)
    • File permissions: Set correct chmod permissions (644 for files, 755 for folders)
    • Firewall: Configure server firewall rules

What is a Data Layer?

A data layer is a structured way to pass information between the frontend UI and backend services. In web development, it typically involves JSON data, JavaScript objects, and API calls.

🔀 Element 6: Setup Version Control (Git)

💡 Why Version Control?

Version control tracks every change you make to your code, lets you revert to previous versions, and enables team collaboration. Git is the industry standard, and GitHub is the most popular platform for hosting Git repositories.

Typical Git Workflow

Terminal
# 1. Initialize project
git init
git remote add origin https://github.com/ninazmul/my-project.git

# 2. Stage and commit changes
git add .
git commit -m "Initial commit: project setup"

# 3. Push to GitHub
git push -u origin main

# 4. Create a feature branch
git checkout -b feature/homepage

# 5. Make changes, then commit
git add .
git commit -m "Add homepage layout"

# 6. Merge back to main
git checkout main
git merge feature/homepage
git push origin main
