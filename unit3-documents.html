Unit 3: Prepare Documents and Create Presentations for Client

Unit Code: SU-ICT-11-L2-V1
This unit covers creating, formatting, and finalizing professional documents and PowerPoint presentations, designing slide layouts, applying storytelling techniques, and delivering presentations to stakeholders.

📋 Overview

As a web designer, you'll frequently need to create professional documents — project proposals, client reports, design briefs — and deliver compelling presentations. This unit builds your skills in both MS Word and PowerPoint to communicate effectively with clients and stakeholders.

📁 Element 1: Prepare for Document Creation

PC 1.1 – 1.7

Setting Up for Professional Document Work

Safety first: Follow safe work practices and wear PPE as per workplace safety standards. Keep work areas clean and organized.

Software preparation:

  • Microsoft Word — Industry standard for business documents
  • LibreOffice Writer — Free, open-source alternative
  • WPS Office Free Writer — Lightweight free option
  • Google Docs — Cloud-based, great for collaboration

Font availability: Ensure both Bangla (Bijoy, Avro) and English fonts are installed and working.

Identify job requirements: Understand the document type, audience, and branding guidelines before starting.

📝 Element 2: Create and Format MS Word Documents

PC 2.1 – 2.6

Document Creation Process

Step 1: Start with a blank document or use a template that matches your requirements.

Step 2: Insert and arrange content logically — title, headings, body text, images, tables.

Step 3: Set up page layout:

  • Page Orientation: Portrait (default) or Landscape
  • Page Size: A4 (210 × 297mm) is standard in Bangladesh
  • Margins: Top, Bottom, Left, Right (default: 1 inch each)
  • Header and Footer: Company logo, page numbers, document title
  • Columns: Single, double, or custom layouts

Step 4: Apply consistent formatting:

Formatting Guide

FontFace, Size, Color, Style (Bold, Italic, Underline)Use max 2-3 fonts; 12pt for body, 14-16pt for headings
ParagraphAlignment (Left, Center, Right, Justify), IndentationLeft-align body text; justify for formal documents
ListsBullet points, Numbered listsUse bullets for unordered items, numbers for sequences
Line SpacingSingle, 1.15, 1.5, Double1.15 or 1.5 for readability
ImagesSize with wrapping (In Line, Square, Tight, Behind)Square wrapping for most layouts
Format PainterCopy formatting from one selection to anotherDouble-click for multiple applications
💡 Pro Tip: Use Styles

Instead of manually formatting each heading, use Word's built-in Heading 1, Heading 2, Heading 3 styles. This ensures consistency and lets you auto-generate a Table of Contents.

💾 Element 3: Finalize and Save Documents

PC 3.1 – 3.5

Review, Export, and Backup

Review checklist:

  • ✅ Check formatting consistency throughout
  • ✅ Run spell check and grammar check
  • ✅ Verify accessibility features (alt text for images, proper heading structure)
  • ✅ Check page numbers and references

File formats:

  • .docx — Editable Word format (default for working documents)
  • .pdf — Non-editable, universal format (use for final delivery)

Backup strategies:

  • Save copies on secure physical storage (USB, external drive)
  • Save copies on cloud storage (Google Drive, OneDrive, Dropbox)
  • Use version naming: proposal_v1.docx, proposal_v2.docx

Step 5: Collect and organize content for slides.

🎨 Element 5: Design Slide Layouts and Apply Storytelling

PC 5.1 – 5.6

Slide Design Principles

  • Insert slides with suitable layouts (title, content, comparison, blank, etc.)
  • Design with appropriate fonts, colors, and visual hierarchy
  • Highlight key messages using concise text and visual elements
  • Apply storytelling techniques for logical flow
  • Plan and integrate visual aids in a logical, timely manner

📖 Storytelling Techniques for Presentations

🎭 Storytelling Framework

1. Narrative Structure:

  • Beginning: Hook the audience — present the problem or opportunity
  • Middle: Present your solution, evidence, and process
  • End: Conclude with results, next steps, and call to action

2. Audience Focus: Tailor your message, use empathy-driven content, include relatable examples

3. Visual Hierarchy: One idea per slide, emphasize key points, maintain logical flow

4. Emotional Engagement: Use case studies, testimonials, humor, and appeals to values

5. Data Visualization: Use infographics, charts, and diagrams to simplify complex ideas

6. Analogies & Metaphors: Simplify concepts by relating them to everyday ideas

7. Smooth Transitions: Reference previous points to maintain coherence across slides

8. Call to Action (CTA): Clear next steps or recommendations in the conclusion

✨ Element 6: Furnish and Finalize Presentation

PC 6.1 – 6.8

Polishing Your Presentation

Animations: Use sparingly and purposefully — Entrance, Emphasis, Motion Path, Exit effects.

Review process:

  • Run presentation from beginning and from current slide to check flow
  • Check consistency and readability against branding guidelines
  • Gather feedback from peers or stakeholders
  • Make revisions based on feedback received
  • Maintain collaboration throughout the revision process

Save formats: .pptx (default), .pptm (with macros), .ppt (legacy), .pdf (for distribution)

Backup: Save copies securely to prevent data loss.

🖨️ Element 7: Print & Transfer Document

PC 7.1 – 7.5

Print Settings and Document Transfer

Print settings to configure:

  • Paper size: A4, Letter, Legal, Custom
  • Print type: Single-sided or Both-sided (Duplex)
  • Page selection: Odd/Even pages, specific page ranges
  • Collation: Collated (1,2,3...1,2,3) or Uncollated (1,1,1...2,2,2)
  • Orientation: Portrait or Landscape
  • Margins: Normal, Narrow, Wide
  • Pages per sheet: 1, 2, 4, 6, 9, 16

Always check Print Preview before printing to verify accuracy and alignment.

Transfer media: USB pen drive, portable hard drive, or optical disc for secure physical transfer.

🎤 Element 8: Deliver Presentation and Gather Feedback

PC 8.1 – 8.5

Professional Presentation Delivery

  • Deliver confidently using appropriate visual aids and speaking techniques
  • Maintain eye contact with the audience, speak clearly and at moderate pace
  • Gather feedback systematically from stakeholders (clients, supervisors, team)
  • Analyze feedback and identify areas for improvement
  • Integrate feedback into future presentations
💡 Presentation Delivery Tips

✅ Practice your presentation at least 3 times before the actual delivery

✅ Arrive early to test equipment (projector, laptop, audio)

✅ Use the 10-20-30 Rule: Max 10 slides, 20 minutes, minimum 30pt font

✅ Prepare for Q&A — anticipate questions your audience might ask

✅ Send a follow-up summary email after the presentation

Part 2: Written & Oral Questions with Detailed Answers

Basic
Q1: Explain the difference between 'Save' and 'Save As' functions when managing web project documents.

Save (Ctrl + S): Overwrites the currently open document with recent modifications, maintaining the existing file name, directory path, and file format.

Save As (F12 or Ctrl + Shift + S): Creates a completely new independent copy of the document. It enables the user to assign a new file name (e.g., Client_Proposal_v2.docx), choose an alternative folder destination, or convert to a different file format (such as PDF, Plain Text, or Word Template .dotx).

Basic
Q2: What is the role of Margins, Orientation, and Paper Size when preparing a print-ready document in MS Word?

Margins: Define the blank boundary between the edge of the paper and the printable content. Standard formal documents use Normal margins (1 inch / 2.54 cm all around) to ensure aesthetic balance and binding clearance.

Orientation: Determines page alignment. Portrait (vertical) is standard for letters, reports, and contracts; Landscape (horizontal) is used for wide data tables, Gantt charts, and mockups.

Paper Size: Ensures layout coordinates match physical printers. Standard international documentation uses A4 (210 x 297 mm), while North American corporate clients frequently require Letter (8.5 x 11 inches).

Basic
Q3: List four standard keyboard shortcuts in Microsoft Word and PowerPoint that enhance document production efficiency.
  • Ctrl + C / Ctrl + V / Ctrl + X: Copy, Paste, and Cut selected content.
  • Ctrl + Z / Ctrl + Y: Undo and Redo the last action.
  • Ctrl + K: Insert or edit an interactive hyperlink to an external website or internal document heading.
  • F5 (in PowerPoint): Launch the slide show presentation from slide 1 (or Shift + F5 from the current slide).
Basic
Q4: What is the function of the Spell Check and Proofing tools in professional client communication?

The Proofing tools (F7 in Office suite) scan documents against localized dictionaries and grammatical rules to detect typos, spelling errors, grammatical inconsistencies, and repeated words. In professional web design proposals, grammatical errors undermine technical credibility and brand perception. Activating proofing guarantees that client proposals meet high professional publishing standards.

Intermediate
Q6: How do you automate an interactive Table of Contents (TOC) in MS Word, and why is this critical for technical documentation?

Implementation Steps:

  1. Apply semantic heading styles throughout the document (Heading 1 for main chapters, Heading 2 for sub-sections, Heading 3 for topics).
  2. Place the cursor on the designated TOC page.
  3. Navigate to the References tab on the ribbon and select Table of Contents.
  4. Choose an automated style. Word scans the document tags and generates clickable chapter listings with matching page numbers.
  5. Whenever content changes or pages shift, right-click the TOC and select Update Field -> Update entire table.

Why Critical: In long technical specifications or client contracts (20+ pages), automated TOC eliminates manual errors, allows instant Ctrl+Click jumping for readers, and exports as interactive bookmarks in PDF documents.

Intermediate
Q7: Explain how the Slide Master in PowerPoint enforces brand consistency across large presentation decks.

The Slide Master acts as the architectural blueprint of a PowerPoint presentation. Changes made to the Slide Master automatically propagate across every layout and slide in the deck:

  • Logo & Watermark Placement: Pins company emblems to exact coordinates so they remain stationary across slides.
  • Typography Hierarchy: Dictates primary header font families (e.g. Outfit Bold 36pt) and body text styling (e.g. Inter Regular 18pt).
  • Color Palette: Locks brand theme colors into color pickers for shapes, charts, and bullet points.
  • Custom Layouts: Enables custom layouts (e.g., side-by-side device mockups, quote testimonials) that team members can insert with one click.
Intermediate
Q8: What checklist should a web designer complete before walking into a client presentation meeting?

Technical & Equipment Checklist:

  • Hardware & Cables: Verify laptop charger, HDMI/VGA adapters (dongles), and a wireless presentation remote/clicker with working batteries.
  • Display Settings: Test projector connection via Win + P (set to 'Extend' mode) to confirm 1080p resolution and correct color calibration.
  • Offline Redundancy: Save local copies of the .pptx presentation and a standalone PDF version on a USB thumb drive in case cloud storage or Wi-Fi fails.
  • Media Playback: Test all embedded prototype screen-recordings and audio clips to ensure playback without internet dependency.
  • System Hygiene: Close personal messaging apps (Slack, WhatsApp, email) and turn on Windows 'Focus Assist' / macOS 'Do Not Disturb' to prevent embarrassing popup notifications during screen sharing.
Advanced
Q9: Describe Nancy Duarte's storytelling framework and how to apply it when pitching a web redesign project.

Nancy Duarte's presentation storytelling framework relies on creating dramatic tension by continuously alternating between 'What Is' (the current flawed reality) and 'What Could Be' (the aspirational, rewarding future):

  • 1. The Hook (The Status Quo): Establish the baseline: show the client's current website metrics (e.g., 68% mobile bounce rate, outdated non-responsive UI, 4.2s load speed).
  • 2. The Call to Adventure: Introduce the vision of a modernized digital storefront that outpaces key competitors.
  • 3. The Conflict & Resolution Cadence: Alternate pain and relief. For every technical hurdle (e.g., legacy database integration), present your clean engineering solution (REST API microservices).
  • 4. The Climax (The New Bliss): Unveil the interactive prototype, walking through an effortless 3-click checkout experience.
  • 5. The Call to Action: Conclude with a clear milestone roadmap, resource requirements, and immediate sign-off steps.
Advanced
Q10: How should a web professional manage and document client feedback gathered during and after a design presentation?

A structured post-presentation feedback protocol includes:

  1. Active Note-Taking: Appoint a dedicated scribe to record verbatim client comments, timestamped slide numbers, and questions raised during Q&A.
  2. Clarification & Categorization: Ask clarifying questions before responding. Group feedback into Bug / Error, Design Preference, Scope Expansion, or Strategic Pivot.
  3. Client Meeting Minutes (MoM): Within 24 hours of the presentation, email a formal 'Minutes of Meeting' document summarizing agreed decisions, assigned owners, and target completion dates.
  4. Change Request Impact Analysis: For feedback requesting features outside the signed SOW, provide an official Change Request (CR) documenting budget and timeline implications before executing modifications.
Advanced
Q11: Explain the technical process and security implications of sanitizing and password-protecting PDF deliverables before client distribution.

Sanitization & Redaction:

  • Documents often store hidden metadata: author names, revision history, internal network paths, and deleted comments.
  • Using Adobe Acrobat's Remove Hidden Information / Sanitize Document scrubs metadata, embedded thumbnails, and invisible script layers.
  • True redaction permanently removes underlying characters and graphics from the PDF content stream, unlike simple colored blackout boxes which can be selected or copied.

Password Security:

  • Document Open Password: Restricts viewing; the PDF cannot be opened or read without the decryption key (AES-256 bit encryption).
  • Permissions / Owner Password: Allows reading but prohibits printing, copying text/images to clipboard, or modifying annotations without administrative clearance.
Advanced
Q12: How do you resolve major projector aspect ratio, font substitution, and color distortion issues when presenting at an unfamiliar client venue?

Resolution Strategies:

  • Aspect Ratio Mismatch (4:3 vs 16:9): In PowerPoint, navigate to Design -> Slide Size. If the venue only has an older 4:3 projector, verify content fits without clipping; if modern, standard 16:9 widescreen prevents side letterboxing.
  • Font Substitution: If the client machine lacks custom corporate web fonts (e.g. Poppins), the OS substitutes fallback fonts like Arial or Times New Roman, breaking text alignment. Prevent this by embedding fonts (Options -> Save -> Embed fonts in file) or saving a high-resolution PDF presentation deck.
  • Projector Color Washout: Cheap or aged projector bulbs severely wash out low-contrast pastels and light grays. Enhance contrast in advance by using bold visual accents, high-contrast dark text (#111827) on pure white cards, and avoiding ultra-thin typography.
