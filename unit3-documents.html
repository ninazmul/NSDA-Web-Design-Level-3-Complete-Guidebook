Unit 3: Prepare Documents and Create Presentations for Client

Unit Code: SU-ICT-11-L2-V1
This unit covers creating, formatting, and finalizing professional documents and PowerPoint presentations, designing slide layouts, applying storytelling techniques, and delivering presentations to stakeholders.

📋 Overview

As a web designer, you'll frequently need to create professional documents — project proposals, client reports, design briefs — and deliver compelling presentations. This unit builds your skills in both MS Word and PowerPoint to communicate effectively with clients and stakeholders.

📁 Element 1: Prepare for Document Creation

PC 1.1 – 1.7

Setting Up for Professional Document Work

Safety first: Follow safe work practices and wear PPE as per workplace safety standards. Keep work areas clean and organized.

Software preparation:

  • Microsoft Word — Industry standard for business documents
  • LibreOffice Writer — Free, open-source alternative
  • WPS Office Free Writer — Lightweight free option
  • Google Docs — Cloud-based, great for collaboration

Font availability: Ensure both Bangla (Bijoy, Avro) and English fonts are installed and working.

Identify job requirements: Understand the document type, audience, and branding guidelines before starting.

📝 Element 2: Create and Format MS Word Documents

PC 2.1 – 2.6

Document Creation Process

Step 1: Start with a blank document or use a template that matches your requirements.

Step 2: Insert and arrange content logically — title, headings, body text, images, tables.

Step 3: Set up page layout:

  • Page Orientation: Portrait (default) or Landscape
  • Page Size: A4 (210 × 297mm) is standard in Bangladesh
  • Margins: Top, Bottom, Left, Right (default: 1 inch each)
  • Header and Footer: Company logo, page numbers, document title
  • Columns: Single, double, or custom layouts

Step 4: Apply consistent formatting:

Formatting Guide

CategoryOptionsBest Practice
FontFace, Size, Color, Style (Bold, Italic, Underline)Use max 2-3 fonts; 12pt for body, 14-16pt for headings
ParagraphAlignment (Left, Center, Right, Justify), IndentationLeft-align body text; justify for formal documents
ListsBullet points, Numbered listsUse bullets for unordered items, numbers for sequences
Line SpacingSingle, 1.15, 1.5, Double1.15 or 1.5 for readability
ImagesSize with wrapping (In Line, Square, Tight, Behind)Square wrapping for most layouts
Format PainterCopy formatting from one selection to anotherDouble-click for multiple applications
💡 Pro Tip: Use Styles

Instead of manually formatting each heading, use Word's built-in Heading 1, Heading 2, Heading 3 styles. This ensures consistency and lets you auto-generate a Table of Contents.

💾 Element 3: Finalize and Save Documents

PC 3.1 – 3.5

Review, Export, and Backup

Review checklist:

  • ✅ Check formatting consistency throughout
  • ✅ Run spell check and grammar check
  • ✅ Verify accessibility features (alt text for images, proper heading structure)
  • ✅ Check page numbers and references

File formats:

  • .docx — Editable Word format (default for working documents)
  • .pdf — Non-editable, universal format (use for final delivery)

Backup strategies:

  • Save copies on secure physical storage (USB, external drive)
  • Save copies on cloud storage (Google Drive, OneDrive, Dropbox)
  • Use version naming: proposal_v1.docx, proposal_v2.docx

📊 Element 4: Prepare PowerPoint Presentations

PC 4.1 – 4.5

Creating a Professional Presentation

Step 1: Create a new presentation from blank or a template library.

Step 2: Select slide size based on needs — Standard (4:3) or Widescreen (16:9, recommended).

Step 3: Identify audience needs and presentation objectives.

Step 4: Create or customize a Slide Master for consistent branding — logo, colors, fonts, background.

Step 5: Collect and organize content for slides.

🎨 Element 5: Design Slide Layouts and Apply Storytelling

PC 5.1 – 5.6

Slide Design Principles

  • Insert slides with suitable layouts (title, content, comparison, blank, etc.)
  • Design with appropriate fonts, colors, and visual hierarchy
  • Highlight key messages using concise text and visual elements
  • Apply storytelling techniques for logical flow
  • Plan and integrate visual aids in a logical, timely manner

📖 Storytelling Techniques for Presentations

🎭 Storytelling Framework

1. Narrative Structure:

  • Beginning: Hook the audience — present the problem or opportunity
  • Middle: Present your solution, evidence, and process
  • End: Conclude with results, next steps, and call to action

2. Audience Focus: Tailor your message, use empathy-driven content, include relatable examples

3. Visual Hierarchy: One idea per slide, emphasize key points, maintain logical flow

4. Emotional Engagement: Use case studies, testimonials, humor, and appeals to values

5. Data Visualization: Use infographics, charts, and diagrams to simplify complex ideas

6. Analogies & Metaphors: Simplify concepts by relating them to everyday ideas

7. Smooth Transitions: Reference previous points to maintain coherence across slides

8. Call to Action (CTA): Clear next steps or recommendations in the conclusion

✨ Element 6: Furnish and Finalize Presentation

PC 6.1 – 6.8

Polishing Your Presentation

Animations: Use sparingly and purposefully — Entrance, Emphasis, Motion Path, Exit effects.

Review process:

  • Run presentation from beginning and from current slide to check flow
  • Check consistency and readability against branding guidelines
  • Gather feedback from peers or stakeholders
  • Make revisions based on feedback received
  • Maintain collaboration throughout the revision process

Save formats: .pptx (default), .pptm (with macros), .ppt (legacy), .pdf (for distribution)

Backup: Save copies securely to prevent data loss.

🖨️ Element 7: Print & Transfer Document

PC 7.1 – 7.5

Print Settings and Document Transfer

Print settings to configure:

  • Paper size: A4, Letter, Legal, Custom
  • Print type: Single-sided or Both-sided (Duplex)
  • Page selection: Odd/Even pages, specific page ranges
  • Collation: Collated (1,2,3...1,2,3) or Uncollated (1,1,1...2,2,2)
  • Orientation: Portrait or Landscape
  • Margins: Normal, Narrow, Wide
  • Pages per sheet: 1, 2, 4, 6, 9, 16

Always check Print Preview before printing to verify accuracy and alignment.

Transfer media: USB pen drive, portable hard drive, or optical disc for secure physical transfer.

🎤 Element 8: Deliver Presentation and Gather Feedback

PC 8.1 – 8.5

Professional Presentation Delivery

  • Deliver confidently using appropriate visual aids and speaking techniques
  • Maintain eye contact with the audience, speak clearly and at moderate pace
  • Gather feedback systematically from stakeholders (clients, supervisors, team)
  • Analyze feedback and identify areas for improvement
  • Integrate feedback into future presentations
💡 Presentation Delivery Tips

✅ Practice your presentation at least 3 times before the actual delivery

✅ Arrive early to test equipment (projector, laptop, audio)

✅ Use the 10-20-30 Rule: Max 10 slides, 20 minutes, minimum 30pt font

✅ Prepare for Q&A — anticipate questions your audience might ask

✅ Send a follow-up summary email after the presentation

🎯 NSDA Exam Preparation: Question Bank & MCQs

High-frequency exam questions covering document preparation, proposal writing, and client presentations for NSDA Level 3 assessments.

Part 1: Multiple Choice Questions (MCQs)

Basic
1. When finalizing a project proposal or contract to send to a client for review, which file format should you export to preserve typography, pagination, and prevent accidental editing across different operating systems?
A .txt (Plain Text Document)
B .pdf (Portable Document Format)
C .docx (Word Document)
D .rtf (Rich Text Format)
View Correct Answer & Explanation
Correct Answer: B — PDF locks formatting, embedded fonts, and page layouts so the document renders identically on any computer or mobile device.
Intermediate
2. In professional PowerPoint presentation design, what is the primary purpose of editing the Slide Master?
A To check grammatical errors in body text
B To apply unified branding, color palettes, logos, and font styles across every slide automatically
C To reduce presentation file size by 90%
D To set a password on the presentation
View Correct Answer & Explanation
Correct Answer: B — The Slide Master controls the default design hierarchy, ensuring consistent visual branding without having to format slides individually.
Advanced
3. What does Guy Kawasaki's famous 10/20/30 Rule of PowerPoint presentation recommend?
A 10 slides, 20 minutes duration, minimum 30-point font size
B 10 minutes duration, 20 slides, 30 words per slide
C 10 animations, 20 bullet points, 30 seconds per slide
D 10 team members, 20 graphics, 30-page handout
View Correct Answer & Explanation
Correct Answer: A — 10 slides keep the pitch concise; 20 minutes allows ample time for discussion/Q&A; 30pt font ensures readability and prevents cluttering slides with walls of text.

Part 2: Written & Oral Questions with Detailed Answers

Basic
Q1: Explain the difference between "Save" and "Save As" functions when managing web project documents.

Save (Ctrl+S): Overwrites the existing file with your latest changes, preserving the same file name, location, and file format.

Save As (F12): Creates a completely new duplicate copy of the document, allowing you to specify a new file name (e.g. Proposal_v2.docx), choose a different directory location, or convert to another file format (such as PDF, Plain Text, or Template).

Intermediate
Q2: Outline the essential sections required in a professional Web Design Proposal document for a corporate client.
  1. Executive Summary & Objective: Overview of client challenges and the proposed digital solution.
  2. Scope of Work (SOW): Detailed list of deliverables (number of pages, wireframes, custom UI, responsive CSS, forms, CMS integration).
  3. Technical Specifications: Target tech stack (HTML5, CSS3, JavaScript, framework, hosting, SSL).
  4. Project Milestones & Timeline: Phased Gantt schedule (Discovery, UI Design, Development, Testing, Launch).
  5. Budget & Payment Terms: Breakdown of costs and milestone-based invoicing (e.g. 30% upfront, 40% design approval, 30% deployment).
  6. Terms, Maintenance & Sign-off: Post-launch warranty, revision policies, and client signature authorization.
Advanced
Q3: How do you apply visual storytelling principles to pitch a web redesign to executive stakeholders?

Structure the presentation around a clear narrative arc:

  • 1. The Hook (Current Reality): Show real customer pain points — bounce rates, slow mobile loading, or confusing navigation backed by analytics data.
  • 2. The Conflict / Opportunity: Demonstrate revenue or brand opportunities lost to competitors due to an outdated user experience.
  • 3. The Solution (The Hero): Reveal the new responsive design prototype, demonstrating user flows, intuitive navigation, and clean visual hierarchy.
  • 4. Tangible Proof: Present expected metrics (speed optimization, accessibility score, mobile conversion).
  • 5. The Call to Action (Next Steps): Conclude with a clear roadmap and approval milestone.
